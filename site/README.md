# Website (gully-to-glory developer site)

One static page: `index.html` (no build step), `privacy.html` (copy of `store/privacy-policy.html`),
`app-ads.txt` (AdMob seller line), images in `img/`, fonts in `fonts/` (OFL).

It is published from the `sharuque-dotcom.github.io` repository so that `app-ads.txt` sits at the
domain root (`https://sharuque-dotcom.github.io/app-ads.txt`), which is where AdMob looks for it.
Copy this folder's files to the root of that repository to update the live site.
